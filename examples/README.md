# examples/

Runnable, end-to-end scripts demonstrating the framework once models exist —
e.g. "load a CSV, run the moving-average factor, inspect the tracked
experiment." Each example should be small, self-contained, and runnable with
no configuration beyond what's in the script itself.

Nothing lives here yet. Examples arrive alongside the first working model in
Phase 3 (see `ROADMAP.md`) — an example without a real model behind it would
just be a mockup, which isn't in keeping with this project's validation
philosophy.
